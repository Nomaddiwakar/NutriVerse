# NutriVerse 3D | Immersive AI Health & Nutrition Coach

NutriVerse is an enterprise-grade, high-performance 3D Health and AI Nutrition SaaS platform built using React 19, TypeScript, NestJS, PostgreSQL, Redis, and Three.js.

---

## 🚀 Key Features

*   **Immersive 3D Parallax Space**: Renders custom models of DNA, Cardiovascular Overloads, and Neural Networks that shift based on scroll sections.
*   **AI Food Scanner**: Multi-input scanner utilizing camera captures, file drags, and paste inputs to identify calories, macronutrients, and vitamins.
*   **AI Chat Nutrition Coach**: Speech-enabled conversational RAG assistant supporting PCOS, Diabetes, and Keto targets.
*   **Body Analysis Morpher**: Slider-driven metabolic profile outlining body shape changes dynamically.
*   **Consolidated Gamification progression**: Level and XP logs, daily quests triggers, and custom golden trophy mesh rooms.
*   **Secure Authentication & Billing**: OAuth (Google & Apple ID), JWT validators, and Stripe checkouts.

---

## 🛠️ Installation & Run Settings

### 1. Backend Ingestions (NestJS / Node)
```bash
cd backend
npm install
npm run start:dev
```

### 2. Frontend Interface (Vite / React)
```bash
npm install
npm run dev
```
Vite launches on port `5173`. Access http://localhost:5173.
